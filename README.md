# SongShub

A high-scale, enterprise-grade media streaming platform powered by a Google Spreadsheet as its CMS.

## Features

- Mode switching between Movies and Songs
- Multi-layer filtering (Type → Language → Media Format)
- YouTube embeds with custom controls
- Auto Mode for continuous playback
- Responsive design

## Tech Stack

- Next.js 14 (App Router)
- React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- Google Sheets API v4 (CMS)
- ETL sync pipeline

## Getting Started

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
